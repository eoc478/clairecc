# Design Process 𓆝 𓆟 𓆞 𓆝 𓆟
I had orignally wanted to do something about gambling but the more I thought about it, I realized that I was overestimating my abilities. I couldn't even think of the questions. I thought of this current idea when I was working with my friends and we were talking about how finals season was being extra brutal this semester. We always joke around and say, "finals season or my final season?"

I decided to use that question as the base of my quiz/tool. I wanted it to calculate how cooked the user would be based on stress, assignments, and sleep (or lack of it). I still wanted to add some kind of gambling aspect, so I created _Pity Points_, where the user could gamble away or spend on items at the end of the project.

# Challenges (too many!) 𓆝 𓆟 𓆞 𓆝 𓆟
This project made me HATE javascript. I'm not good at learning new coding languages and I had the same experience when we learned HTML/CSS. What I don't like about the curriculum is that we have to learn a whole new coding language near the end of the semester when finals season rolls around. It honestly just kills motivation. If I didn't have a heavy workload in all of my other classes, I think I would've been fine with the pacing and generally putting in the time to understand it more. It's almost embarassing how much I didn't know and how much I struggled with this project. 

I had so much trouble with the pity points, I almost just gave up on the whole project. Getting the points to add properly and transfer over to the next page was **HELL.** I thought it would be pretty simple but apparently loadStorage can't do math?
